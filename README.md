#  Smart Room AC Control System

An intelligent, logic-driven automation project designed to regulate room air conditioning dynamically. This system evaluates real-time environmental factors while respecting user preferences to make smart automated decisions.

##  Project Overview
This project bridges the gap between basic Python syntax and real-world conditional programming. By combining multiple logical operators, environmental inputs, and safety overrides, it simulates a modern smart-home automation feature entirely through clean backend logic.

##  Key Features
* **Multi-Factor Environmental Monitoring:** Accurately processes custom inputs for both ambient room temperature and relative humidity levels.
* **Smart Decision Engine:** Automatically triggers the cooling system based on strict threshold rules (such as high temperature or high humidity conditions).
* **User Preference Safety Override:** Features a manual control flag that ensures the system respects user input, preventing unwanted automated activations.
* **Advanced Logic Design:** Implements complex boolean logic and proper operator precedence using structured grouping to ensure error-free evaluations.

##  Core Concepts Applied
* **Conditional Statements:** Leveraging structured decision-making blocks.
* **Logical Operators:** Mastering the synergy and behavior of `and` and `or` conditions.
* **Operator Precedence:** Utilizing grouping to control the exact order of logical execution.
* **Boolean State Management:** Handling system overrides using state flags.

##  Future Enhancements
* Expanding the script into a continuous loop for real-time monitoring.
* Adding extended climate parameters like air quality or fan speed control.
